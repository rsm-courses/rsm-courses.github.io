## About this course

A Carpentry-style course covering the basics of R for research software and
data work. Run jointly with VU, UvA and HvA.

## Topics covered

- R basics and RStudio
- Data wrangling
- Version control with Git/GitHub (integrated into this course rather than
  taught separately)
